## Kurulum

1. APK indirme bağlantısını Android telefonda açın.
2. Dosyayı indirip açın. Android isterse ilgili tarayıcı/dosya yöneticisi için kurulum izni verin.
3. Mevcut uygulamanın üzerine güncelleyin.

Dosyanın SHA-256 özeti [SHA256SUMS.txt](SHA256SUMS.txt) içinde, sürüm bilgisi [version.json](version.json) içindedir.
